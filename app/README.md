# ЛистОК — веб-приложение

Интерфейс подготовки рабочих листов для математики и физики.

- [Описание проекта и команды](../README.md)
- [Локальный запуск, GigaChat и LaTeX](../RUN.md)
- [Презентация для жюри](../presentation.pdf)

Основной локальный запуск: `python run_local.py` из корня репозитория. Конфигурация GigaChat читается из корневого `.env`. Сам файл и реальные ключи в репозиторий не включаются.
