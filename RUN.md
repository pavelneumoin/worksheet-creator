# Запуск и проверка ЛистОК

## Windows

Из корня проекта, где находится `run_local.py`:

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_local.py
```

Если `.venv` уже настроено, повторять создание не нужно. Адрес — http://127.0.0.1:3005, остановка — Ctrl+C. Другой порт: `run_local.py --port 3015`. Вместе с сервером запускаются обработчики ИИ и сборки; при остановке закрываются их процессы. `--no-workers` предназначен только для диагностики: новые задачи без обработчика не принимаются.

## Linux/macOS без Docker

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python run_local.py
```

Нужен **XeLaTeX** из TeX Live или MiKTeX с пакетами `babel` (русский язык), `fontspec`, `amsmath`, `amssymb`, `multicol`, `geometry`, `tikz`, `xcolor`, `fancyhdr`, `lastpage`. CMU Serif и CMU Typewriter Text входят в репозиторий и копируются в каталог сборки; устанавливать шрифты в систему не требуется. Для существующего MiKTeX добавьте пакеты командой `miktex packages install fancyhdr lastpage`. Новые OpenType-шаблоны требуют XeLaTeX, pdfLaTeX для них не подходит. Сборка не скачивает пакеты автоматически и не отправляет документы во внешний сервис.

## Настройка ИИ и MAX

Создайте `.env` из `.env.example`, только если файла ещё нет. В рабочей копии могут уже быть ключи: не перезаписывайте существующий файл. Ручные примеры доступны без GigaChat.

| Настройка                         | Назначение                                                             |
| --------------------------------- | ---------------------------------------------------------------------- |
| `GIGACHAT_CREDENTIALS`            | Серверный ключ авторизации GigaChat API                                |
| `GIGACHAT_SCOPE`                  | Scope проекта из кабинета провайдера                                   |
| `GIGACHAT_MODEL`                  | Модель проекта с поддержкой изображений                                |
| `GIGACHAT_BASE_URL`               | `https://api.giga.chat/v1`                                             |
| `GIGACHAT_CA_BUNDLE_FILE`         | При необходимости абсолютный путь к PEM-набору доверенных сертификатов |
| `LATEX_COMPILER`                  | Необязательный путь к XeLaTeX/pdfLaTeX                                 |
| `LATEX_TIMEOUT_SECONDS`           | Тайм-аут одного запуска компилятора, по умолчанию 60 секунд            |
| `MAX_BOT_TOKEN`                   | Токен для проверки API и подписей запуска MAX                          |
| `MAX_BOT_USERNAME`, `MAX_APP_URL` | Имя бота и полный HTTPS-адрес мини-приложения (включая схему)          |

После изменения `.env` перезапустите сервер. Учитель не вводит личный API-ключ в интерфейсе. [Подробный список подключений](docs/ACCESS.md).

Для сертификатов используйте [официальную инструкцию GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates). Не выключайте TLS-проверку. Для Docker путь к PEM должен существовать **внутри контейнера**, файл монтируется read-only; Windows-путь напрямую там не работает.

## Проверка полного сценария

1. Выберите математику, откройте ручной пример.
2. Проверьте три карточки. Ответы: 2 и 3; 19/12; 13.
3. Измените текст задания, удалите или добавьте карточку при необходимости.
4. Выберите клетку / пустое поле / список, 1–2 столбца, число заданий на странице.
5. Отметьте проверку и соберите PDF. В блоке «Задачи» дождитесь результата; можно перезагрузить страницу. Откройте отдельно лист и ответы. В «Исходниках» скачайте LaTeX и архив Marp; в архиве есть тема A4, отдельные ответы и команды сборки.
6. Сохраните лист, откройте «Мои материалы», загрузите его заново и убедитесь, что правки сохранены.
7. Повторите для физики. Контрольные ответы: 32 м; 3 А; 2,7 г/см³.
8. После подключения GigaChat проверьте **настоящие** фотографии. Контрольный пример не заменяет этот тест.
9. В «Моих материалах» нажмите «Поделиться», проверьте содержание и опубликуйте учебный лист. Откройте «Библиотеку»: поиск, предмет, сортировка, просмотр ответов. Для второго независимого локального профиля можно открыть `http://localhost:3005/` вместо `http://127.0.0.1:3005/` в том же браузере.
10. Во втором профиле оцените лист и нажмите «Взять за основу». Изменение своей копии не должно менять исходную публикацию. В профиле автора снимите публикацию и убедитесь, что копия у коллеги осталась. [Правила библиотеки](docs/LIBRARY.md).

## Контейнер и CLI

```bash
docker build -t listok:night7 .
docker compose up -d --wait
docker run --rm --network none listok:night7 python -m unittest discover -s tests -v
docker run --rm --network none listok:night7 python scripts/smoke_pdf.py
docker run --rm --network none listok:night7 python scripts/smoke_queue.py
```

На локальном компьютере Docker не установлен. Образ собран и проверен в [GitHub Actions](https://github.com/pavelneumoin/worksheet-creator/actions/workflows/check.yml?query=branch%3Acodex%2Fqueue-marp-docker). Выберите успешную сборку того же коммита, что и ваш checkout. Готовый образ и SHA256 находятся в артефакте `listok-docker-image`: после распаковки выполните `docker load -i listok-image.tar.gz`, затем `docker compose up -d --no-build --wait`. Нужны `.env` и каталог `.local-certs`; для GigaChat нужен действующий CA-набор. Локальный `.env` не перезаписывайте.

## Хранение и границы

- Материалы, классы, ученики, назначения, сессии, публикации, оценки и авторство копий — SQLite (`LISTOK_DB_PATH`, по умолчанию `app/backend/worksheets.db`). Compose хранит базу в томе `materials`, PDF — в `generated`. Для резервной копии сохраняйте оба тома; `docker compose down -v` удалит их.
- `run_local.py` включает отдельный локальный профиль для каждого браузера только на loopback. Он не выдаётся за MAX-профиль. При очистке cookies этот тестовый профиль теряет вход; настоящий профиль MAX восстанавливается по подписанному ID. Локальные сессии не принимаются в режиме `max`.
- Загрузка хранится в отдельном временном каталоге и удаляется после успеха или ошибки. Для файлов GigaChat выполняется запрос удаления; сбой этого запроса записывается в серверный журнал.
- Ответы создаются ИИ, но их правильность не гарантирована. Статус «проверено» означает подтверждение учителем, не математическое доказательство.
- Слишком длинный лист отклоняется: уменьшите заданий на странице, используйте один столбец или сократите формулу.
- PDF на входе и чат-команды MAX-бота — следующие этапы. Marp, очередь и библиотека реализованы. Серверные сессии MAX реализованы; токен бота проверен, реальный запуск ждёт HTTPS и привязки мини-приложения.

## Вход и личные материалы

В продакшене оставьте `LISTOK_AUTH_MODE=max` (это значение по умолчанию). Заполните `MAX_APP_URL=https://ваш-домен/`, `MAX_BOT_TOKEN` и `MAX_BOT_USERNAME`. Подключите тот же HTTPS-адрес к мини-приложению бота. Приложение использует официальный MAX Bridge и передаёт на сервер только подписанный `initData`, не `initDataUnsafe`.

Сессия действует 7 дней; cookie — HttpOnly, Secure и SameSite=None для MAX webview/iframe. Изменения требуют CSRF-токен, полученный этой сессией. ID владельца не берётся из JSON или query-параметров. Старые записи общего журнала без владельца остаются в БД и не выдаются новым пользователям.

Нативное скачивание MAX использует `WebApp.downloadFile` и ссылку на конкретный комплект сроком 10 минут. Она перестаёт работать при выходе из сессии или удалении связанного материала. Не сохраняйте полные пути `/api/v2/downloads/` в access-логах reverse proxy. Другие пути PDF/TEX требуют действующую сессию владельца.

## Мобильная проверка и живой GigaChat

```powershell
.\.venv\Scripts\python.exe run_local.py
.\.venv\Scripts\python.exe scripts/compare_models.py --run
.\.venv\Scripts\python.exe scripts/smoke_live.py --run
```

Последние две команды расходуют квоту GigaChat и сохраняют результаты в игнорируемой папке `output/qa`. `smoke_live.py` требует уже запущенный локальный сервер. Для проверки без сетевых вызовов используйте unittest и `smoke_pdf.py`.

Для Compose подготовьте `.local-certs/gigachat-ca.pem`: стандартные CA плюс официальный корневой сертификат из [инструкции GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates). Compose монтирует каталог только для чтения и задаёт путь внутри контейнера. Ключи и сертификаты не встраиваются в образ.

Классы и назначение неизменяемой версии: [инструкция](docs/CLASSES.md). Для проверки MAX API в контейнере Compose также задаёт `MAX_CA_BUNDLE_FILE=/app/certs/gigachat-ca.pem`; локальный Windows-путь из `.env` не используется внутри контейнера. Проверка: `docker compose exec listok python scripts/check_connections.py --max`.
