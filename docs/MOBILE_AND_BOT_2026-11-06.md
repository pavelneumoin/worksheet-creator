# Мобильная проверка и чат-бот: текущая итерация

Пользователь подтвердил весь список функций 6 ноября. Публикация сервера и GitHub разрешена; конкурсную работу не отправляем.

- [x] Мобильная проверка по одному ответу: «Нужно внимание», полный список и сохранение черновика.
- [x] Увеличение оригинала, переход к предложенному фрагменту, перемещение и масштаб.
- [x] Частичные баллы 0 / 0,25 / 0,5 / 0,75 / 1; история и корректные отчёты.
- [x] CMU / Computer Modern: качественный набор дробей, индексов, корней и единиц в PDF.
- [x] Бот «Проверить пачку»: PDF → класс/назначение → очередь → ссылка на пачку.
- [x] Бот «На печать сегодня»: задания, бланки класса и ключи.
- [x] Бот «Следующий сомнительный»: фрагмент, ответ, черновые 0 / ½ / 1; итог подтверждается отдельно.
- [x] Бот «Итог урока»: проверено/осталось, трудные задания, PDF отчёта.
- [x] Бот «Повторить ошибки»: черновик по подтверждённым затруднениям, предпросмотр учителю.
- [x] Уведомления о готовности запросов из бота с переходом к результату.
- [x] Тесты API/доступа/повторов, реальный PDF, мобильный браузер, резервная копия, сервер и GitHub Release.

Прежние подтверждённые оценки не меняются при сохранении черновика. Фильтр сомнений не является автоматическим подтверждением; неизвестный ответ не считается нулём. Рамка ИИ служит только подсказкой для просмотра, полный оригинал остаётся доступен. Шкала пока нормирована: максимум 1 за каждое задание; произвольные веса и рубрики — отдельный этап.

## Как пользоваться ботом

| Команда | Сценарий |
|---|---|
| `/check` | Выбрать класс и назначение, отправить один PDF до 40 страниц и 15 МБ. Ожидание действует 30 минут; `/cancel` его отменяет. Файл без выбранного режима вызывает выбор между созданием листа и проверкой. |
| `/next` | Выбрать работу; получить фрагмент, прочитанный ответ и ключ. 0 / ½ / 1 сохраняют черновик. Окончательное подтверждение отдельное; ¼ и ¾ доступны в кабинете. |
| `/summary` | Подтверждено / осталось / не сдали, доля набранных баллов, сложные задания и кнопка PDF. |
| `/repeat` | До шести заданий с выполнением ниже 70% в подтверждённых работах. Кнопка запускает черновик аналогичных задач; ответы нужно проверить до `/pdf`. Имена, коды и ученические ответы в генерацию не передаются. |
| `/today` | Листы и ключи на сегодняшнюю дату по Москве; бланки класса берутся готовые или собираются последовательно. До 20 назначений за запрос. |
| `/quick`, фото, `/лист …` | Прежний быстрый сценарий создания, личная библиотека, `/draft`, проверка учителем, `/pdf`, `/files`. |

Кнопки действий действуют час, одноразовые и связаны с владельцем. Устаревшая карточка не перезаписывает более свежие правки из кабинета. Повтор события MAX не создаёт вторую задачу. Уведомления относятся к обработкам, запрошенным из чата. После неопределённого сетевого сбоя отправка не повторяется автоматически; результат сохраняется в кабинете.

Для готовых бланков с QR строки находятся локально по ровной сетке; область включает номер и видимый ответ. Неуверенная геометрия оставляет полный оригинал. Для обычных фотографий используются необязательные координаты распознавания. Положение рамки не влияет на баллы. Сканы доступны учителю в кабинете 7 дней; отправленный фрагмент также остаётся в его личном чате MAX.

## Приёмка

- 256 Python-тестов и 23 Node-теста; владение файлами, одноразовые кнопки, срок действия, конфликт черновиков, дробные баллы и исключение неподтверждённых результатов.
- Настоящие PDF: четыре шаблона × две колонки, шесть примеров математического набора; CMU Serif и Computer Modern math встроены. Макеты листа и ключей просмотрены.
- Живой GigaChat: два синтетических бланка; числовые ответы сохранены, пустое поле в одном прогоне обозначено `unclear`, балл не назначен. Координаты ИИ не вернул — добавлено локальное определение строк по сетке.
- Edge: восстановление черновика, прямой переход к проверке, 0,5 балла, отдельное подтверждение. Среднее двух учебных работ стало 2,25/3 и 75%; третья неподтверждённая работа исключена. PDF/CSV совпадают.
- Эмуляция касаний: увеличение двумя пальцами с 334% до 706%, перемещение и возврат к целому листу. Это проверка браузера, не испытание на настоящем телефоне.
- Сервер: пять здоровых контейнеров, HTTPS, закрытый доступ к задачам, два прежних материала сохранены. Резервные копии до и после обновления восстановлены отдельно, по 10 файлов.
- Настоящий MAX: изображение фрагмента и два PDF доставлены владельцу; callback нажат в вошедшем веб-клиенте, сервер прислал ответ. PDF скачан и SHA256 совпал с исходником. Длинная подпись мобильной кнопки сокращена до «Проверка ответов», старые кнопки продолжают работать.
- Живой GigaChat на сервере: оба QR, шесть ответов и шесть областей; повторение дробей создало `2/5 + 7/10 = 11/10`, ключ проверен. База этого прогона отдельная и временная.
- Первый Docker-релиз итерации [mobile1](https://github.com/pavelneumoin/worksheet-creator/releases/tag/listok-2026.11.06-mobile1) прошёл CI. Финальный `mobile2` включает короткую подпись меню; номер окончательной сборки фиксируется в журнале выпуска.

## Следующий этап

1. 10–15 настоящих рукописных бланков: дроби, минусы, единицы, зачёркивания, разные МФУ и телефоны. Измерить время на класс, долю ручных исправлений и пропуски.
2. Геометрические метки для перекошенных снимков, несколько страниц решения, выбор окончательного ответа при зачёркивании.
3. Настраиваемые максимумы и рубрики для развёрнутых решений с новой неизменяемой версией критериев.
4. Сохранённые группы затруднений, динамика по темам и повторный мини-зачёт после листа повторения.

API MAX: [callback](https://dev.max.ru/docs-api/methods/POST/answers/), [события](https://dev.max.ru/docs-api/objects/Update/), [загрузка изображений](https://dev.max.ru/docs-api/use-cases/sending-messages/media).
