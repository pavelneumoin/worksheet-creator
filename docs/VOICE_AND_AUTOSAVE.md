# Проверка с автосохранением и лист голосом

## Учителю

Откройте «От учеников» → «Открыть проверку». Ответы, частичные баллы и комментарии
сохраняются после короткой паузы в наборе. Строка над заданиями показывает состояние.
При переходе в другой раздел приложение сначала завершает сохранение.
Сохранённый черновик восстанавливается при следующем открытии работы.

Оценка попадает к ученику и в отчёты только после «Подтвердить результат».
Возврат на исправление сохраняет комментарии к заданиям и прежнюю официальную оценку.
Кнопка «Удалить черновик» позволяет начать проверку заново перед повторным распознаванием.

Если связь пропала, правки остаются на экране. Можно повторить сохранение или скачать
JSON с текущими ответами. Повторный запрос не создаёт дубликат. Изменения из другой
вкладки вызывают сообщение о конфликте вместо перезаписи. При закрытии страницы
до успешного сохранения браузер предупреждает; работа без сети с закрытием вкладки
пока не поддерживается.

## Уведомление ученику

После возврата попытки или подтверждённой бумажной работы бот отправляет ученику
сообщение MAX. В сообщении нет оценки, ФИО и текста замечаний: они доступны только
в личном кабинете. Ссылка не содержит ключа входа. Команда `/my` («Мои работы»)
выдаёт свежую персональную ссылку, если сеанс закончился.

Для доставки ученик должен открыть бота и нажать «Начать». Учитель видит состояние:
в очереди, отправлено, недоступно или доставка не подтверждена. Ошибка MAX не отменяет
возврат работы. Отзыв доступа, закрытый класс или новая попытка отменяют ещё не
отправленное уведомление. Демо-пользователям сообщения не отправляются.

Очередь хранится в SQLite вместе с возвратом. Ограничение частоты MAX повторяется
с задержкой; неоднозначный тайм-аут не повторяется автоматически, чтобы не дублировать
сообщение. Восстановление резервной копии очищает очередь доставки, но сохраняет черновики.

## Рабочий лист голосом

1. В личном чате бота отправьте голосовое до двух минут и 8 МБ.
2. Назовите предмет, класс, тему, число заданий, сложность и оформление.
3. Проверьте текст запроса. При ошибке отправьте `/тема` и полное исправленное описание.
4. Нажмите «Создать лист». Задания и ответы придут в чат и сохранятся в библиотеке.
5. Проверьте черновик и нажмите «Проверил, собрать PDF». Бот пришлёт лист, ответы,
   комплект учителя и отдельный бланк ответов.

Пример: «Математика, восьмой класс. Шесть квадратных уравнений от простых к сложным.
Два столбца, без клеток». `/voice` показывает подсказку, `/draft` восстанавливает
черновик, `/files` повторяет готовые файлы. По одному запросу создаётся один лист
до 12 заданий; настройки и варианты можно изменить в кабинете.

MAX может передать готовую расшифровку аудио; иначе запись распознаётся локально
моделью Vosk small RU 0.22. Аудиофайл удаляется после завершения или отмены задачи.
Новый внешний сервис для распознавания речи не требуется. Математические термины
и числительные могут распознаться неверно: подтверждение текста обязательно.
Качество на настоящих голосовых сообщениях учителей ещё нужно измерить.

Источники: [формат аудио MAX](https://dev.max.ru/docs-api/objects/Message),
[модели Vosk и лицензии](https://alphacephei.com/vosk/models).

## Для запуска

Dockerfile устанавливает FFmpeg, библиотеку Vosk и русскую модель с проверкой SHA256.
Лицензия модели — Apache 2.0; контрольная сумма закреплена в `scripts/install_voice_model.py`.
На локальном Windows пути к модели лучше использовать латиницу.

```powershell
python scripts/install_voice_model.py C:/listok-models
$env:LISTOK_VOSK_MODEL='C:/listok-models/vosk-model-small-ru-0.22'
# ffmpeg должен быть в PATH; иначе задайте LISTOK_FFMPEG полным путём.
```

Декодер принимает только локальные файлы, работает с ограничением времени и длины.
Распознавание выполняется в ограниченном дочернем процессе очереди, не блокируя чат.
Генерация заданий использует уже настроенный текстовый API проекта.
