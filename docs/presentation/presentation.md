<div class="kicker">Реализуемость</div>
<h2>Архитектура уже работает локально</h2>
<div class="flow">
<div><span>01 / ИНТЕРФЕЙС</span><h3>HTML / CSS / JS</h3><p>Фото заданий, предмет, редактирование LaTeX.</p></div>
<div><span>02 / СЕРВЕР</span><h3>Python / Flask</h3><p>Проверка файлов и обращение к ИИ через API.</p></div>
<div><span>03 / ИИ</span><h3>GigaChat</h3><p>Черновик заданий и ответов. Ключ хранится на сервере.</p></div>
<div><span>04 / ВЫПУСК</span><h3>XeLaTeX / PDF</h3><p>Лист A4, отдельные ответы и история в SQLite.</p></div>
</div>
<div class="rule"></div>
<p class="lead">Учителю не нужен личный API-ключ.</p>
<p class="sub">Для школьного запуска нужны HTTPS, отдельный доступ к истории и изолированная сборка LaTeX.</p>
