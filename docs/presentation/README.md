# ЛистОК — исходник презентации Marp

Основная версия для отправки жюри — `presentation.pdf`. Исходный текст слайдов находится в `presentation.md`, оформление — `theme.css`, изображения — `assets/`.

Для редактирования используйте любой текстовый редактор или расширение Marp. Каждый раздел между `---` — отдельный слайд. Комментарии `<!-- ... -->` содержат пояснения и источники для проверяющего. Они добавлены в PDF как заметки-аннотации, не закрывают слайды и не являются текстом выступления.

## Пересборка

Потребуются Node.js 18+ и Chrome/Edge. Установите зависимости в эту папку:

```powershell
npm install
npx marp presentation.md --theme-set theme.css --html --allow-local-files --pdf --pdf-notes --pdf-outlines --browser edge -o presentation.pdf
```

Разрешение локальных файлов необходимо, чтобы Marp прочитал проверенные изображения из `assets/`. Не используйте эту опцию для чужих непроверенных исходников.

## Происхождение материалов

- `hero`, `science`, `team`, `process`, `speed`, `messenger`, `teacher` — иллюстрации, сгенерированные для проекта. Изображение команды не является фотографией реальных участников.
- `app-hero` и `app-editor` — настоящие снимки локального приложения в Edge.
- `math-source` и `physics-source` — контрольные страницы с условиями, подготовленные для демонстрации.
- `math-output` и `physics-output` — рендеры настоящих PDF приложения после проверки содержания и оформления.
- Время 6,8 с и 5,6 с — один измеренный прогон по физике, без времени проверки человеком. Это не среднее, не гарантия скорости и не сравнение с Word.
