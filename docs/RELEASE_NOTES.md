Файлы релиза:
- listok-image.tar.gz — Docker-образ, собранный и проверенный CI этого тега.
- listok-image.sha256 — контрольная сумма образа.
- Исходники, requirements.txt, команды Docker и документация — в репозитории.

Загрузка образа: docker load -i listok-image.tar.gz.
Запуск: подготовить .env по RUN.md, затем docker compose up -d --wait.
Для публичного сервера подключить compose.https.yaml и compose.bot.yaml.
Образ не содержит токенов, приватных ключей или пользовательской базы.
