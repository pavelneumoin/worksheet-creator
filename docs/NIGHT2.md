# Личные материалы, MAX и мобильная проверка

Состояние на 21 октября 2026. Изменения находятся в локальной рабочей копии; готовый MAX-бот и публичное размещение пока не выдаются за выполненные.

## Что работает

- Проверка HMAC-подписи `initData`, свежести до часа и уникальности параметров запуска MAX.
- Серверные отзываемые сессии на 7 дней. Cookie HttpOnly, в режиме MAX — Secure/SameSite=None. CSRF-защита изменений и проверка Origin.
- SQLite-профиль по проверенному ID MAX; один пользователь видит свои материалы на нескольких устройствах. Локальный запуск использует отдельные явно помеченные тестовые профили.
- Черновик можно сохранить до печати. Есть открытие, редактирование, сохранение копии, удаление, поиск по теме/условиям и сортировка. Конфликт версий защищает от перезаписи правок с другого устройства.
- Старые локальные листы переносятся отдельной кнопкой с подтверждением. Материалы не импортируются молча в произвольный MAX-профиль.
- PDF/TEX проверяют владельца, включая старые API и прямой путь скачивания. После изменения содержания старый PDF отсоединяется от новой версии листа.
- Для нативного `WebApp.downloadFile` выдаются ссылки на комплект сроком 10 минут; они отзываются при выходе из сессии. Bridge сохраняется при перезагрузке MAX-вкладки без хранения сырого `initData`.
- Реальные фото и варианты проверены на GigaChat; добавлена ограниченная точная арифметика. [Подробные результаты моделей](GIGACHAT_EVALUATION.md).
- Compose содержит отдельные постоянные тома базы и файлов, сертификаты монтируются только для чтения. Ключи не передаются дочернему TeX-процессу.

## Проверка

**66 автоматических тестов**: подписи/подделки/истёкшие запуски, два пользователя, второе устройство одного пользователя, CSRF/Origin, закрытые старые маршруты, доступ к PDF/TEX, временные ссылки и отзыв, конфликт редактирования, арифметика, очистка фото, ошибки провайдера, неизменённые варианты, разбиение страниц.

Четыре настоящих TeX-макета: математика и физика с клеткой; два столбца/два задания/две страницы; компактный список. Всего 8 PDF (лист + ответы для каждого случая). Дополнительно через мобильный интерфейс собраны лист из настоящей фотографии и его копия в двух столбцах на двух страницах; PDF листов и ответов просмотрены. Заголовок ответов вынесен отдельно, чтобы длинная тема не разрывала слово «ответы».

Мобильная проверка выполнялась **в браузере с viewport 320, 375, 390 и 430 px**, а не на физических телефонах. В библиотеке ширина содержимого равна клиентской ширине (305, 360, 375, 415 px с учётом полосы прокрутки браузера). Проверены:

1. Выбор PNG через настоящий диалог файлов и запрос распознавания.
2. Отображение формул, раскрытие редактора, изменение ответа и снятие вычислительной пометки.
3. Сохранение черновика, сборка PDF, сохранение комплекта, обновление страницы и повторное открытие.
4. Сохранение отдельной копии при сохранном исходном листе, поиск, пустая выдача и сортировка.
5. Повторное открытие материалов после перезапуска сервера.
6. Узкие поля оформления заменены полноширинными; основные элементы имеют высоту от 44 px, поля ввода — шрифт 16 px.

Отчёты и снимки локальной проверки лежат в игнорируемом `output/qa/`. Тесты не обращаются к реальному API; живые проверки запускаются отдельно с `--run`.

## Что подключить дальше

GigaChat уже подключён. Для настоящего MAX-входа нужны `MAX_BOT_TOKEN`, `MAX_BOT_USERNAME` и HTTPS-адрес в `MAX_APP_URL`; тот же адрес должен быть привязан к мини-приложению бота. Секреты заполняются непосредственно в локальном `.env`. [Инструкция подключения](ACCESS.md).

Не проверены без этих доступов: запуск на Android/iOS внутри MAX, фактические cookies в webview, нативная загрузка/скачивание и кнопка «Назад». Их локальные реализации опираются на [валидацию MAX](https://dev.max.ru/docs/webapps/validation) и [MAX Bridge](https://dev.max.ru/docs/webapps/bridge).

Docker Engine здесь отсутствует. Dockerfile/Compose/workflow подготовлены, но образ ещё не собран и не опубликован. До открытого пилота нужны очередь и отдельное окружение компиляции, лимиты нагрузки, политика хранения временных файлов. Публичная библиотека с рейтингом, Marp и команды чат-бота остаются в общем плане.
