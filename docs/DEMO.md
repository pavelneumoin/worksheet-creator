# Демо для учителя и проверяющего

В боте отправьте `/demo` или войдите в кабинет и нажмите **«Посмотреть демо»**.
Создаётся отдельный учебный кабинет этого пользователя. Кнопка **«В мой кабинет»**
возвращает настоящие материалы, классы и школу. Демо не публикуется в общей библиотеке.

## Проверка за несколько минут

1. **Рабочий лист** — откройте готовый PDF, отдельные ответы или комплект учителя.
   Можно изменить задания, шаблон, число столбцов и поля для решения.
2. **Класс и ученики** — восемь кодов и назначенные работы. В маршруте доступны
   фото вымышленного списка и фото заданий для настоящего распознавания.
3. **Проверка ответа** — откройте сомнительный ответ, увеличьте скан, выберите балл
   с шагом 0,25. Сохранение черновика не меняет статистику; подтверждение меняет.
4. **Пачка сканов** — готовая страница с QR для сопоставления с учеником.
5. **Загрузить PDF** — скачайте учебный PDF из маршрута и загрузите в уже выбранную
   работу «Дроби и проценты · загрузка PDF». Три страницы: правильные ответы,
   ошибочный ответ `18` вместо `20`, пустой ответ. Коды должны сопоставиться.
6. **Статистика школы** — три класса, два учебных профиля, результаты по темам,
   подробные PDF/CSV. Рекомендации формируются отдельной кнопкой.

В личной библиотеке есть три готовых материала и черновик. В обмене материалами —
две учебные публикации. В расписании — текущие, прошедшие и будущая работы;
даты создаются относительно московской даты первого входа.

Исходная сводка: 24 подтверждённые работы, четыре ожидают проверки. Пропуски и
неподтверждённые баллы исключены из процента выполнения. После действий пользователя
данные демо меняются и сохраняются; повторный вход не создаёт дубликаты.

Все задания и ученики учебные, результаты подготовлены заранее и обозначены в интерфейсе.
Проверка новых фото/PDF, генерация вариантов и рекомендаций используют обычную очередь
и расходуют квоту подключённого сервиса. В демо действуют те же проверки доступа,
CSRF, версий и подтверждения оценок. Команды `/today`, `/check`, `/next` в чате работают
с настоящим профилем; `/demo` открывает отдельный учебный веб-кабинет.

## Воспроизведение

Готовые CMU PDF входят в образ: `app/backend/assets/demo`. Пересборка исходных образцов:

```bash
python scripts/build_demo_assets.py
python -m unittest discover -s tests -p test_demo_space.py -v
```

Компиляция не запускается при входе: сервер копирует готовые PDF и создаёт только
персональные QR/сканы. Смена кабинета отзывает ранее выданные ссылки скачивания.
Резервная копия сохраняет демо-данные, но исключает активный режим демо и сессии.
