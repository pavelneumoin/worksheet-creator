# Первая ночь: результат и продолжение

Дата: 21 октября 2026. Исходный коммит: `933a8c7`. Изменения пока локальные, отправка в GitHub не выполнялась.

## Сделано

- Проверен исходный проект: 34 регрессионных теста проходили до изменений.
- Создана схема рабочего листа версии 1: задания, ответы, замечания, тема, класс, настройки печати.
- Добавлены API нового сценария и GigaChat-адаптер с отдельным сообщением на каждое изображение и удалением временных файлов.
- Перестроен адаптивный интерфейс: материал → карточки → оформление → PDF. Формулы отображаются через локальный KaTeX. Сложная формула при ручной правке всё ещё представлена математической записью; полноценный визуальный редактор формул не заявляется.
- Добавлены сохранение карточек в браузере, повторное открытие, три действия создания варианта через API.
- Вёрстка теперь сама разбивает задания по страницам, выбирает столбцы и тип поля. Проверяется фактическое число страниц и переполнение. Ответы отдельные, неполные комплекты удаляются.
- Обновлена серверная библиотека GigaChat, закреплены Python-зависимости. Один корневой Dockerfile, Compose с loopback-портом, workflow сборки/тестов и CLI-проверка PDF.
- Подготовлена серверная проверка данных MAX (подпись, срок, уникальность параметров). Это пока не авторизация.
- Название команды и текущие роли приведены к данным пользователя в основном README. Дизайн приведён к светло-серому интерфейсу с цветами официального сайта Сферума.
