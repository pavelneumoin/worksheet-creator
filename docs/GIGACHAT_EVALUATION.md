# Живое сравнение GigaChat — 21 октября 2026

Проверен предоставленный персональный API-доступ (`GIGACHAT_API_PERS`), TLS включён. Ключ находится только в локальном `.env`, CA-набор — в игнорируемом `.local-certs`. В код, документы, образ и отчёты ключи не включаются.

## Как проверяли

Два собственных изображения из `docs/examples`: `math-source.png` и `physics-source.png`. По три задания на каждом. Одинаковые инструкции и схема JSON, `temperature=0.1`, `max_tokens=8000`. Время включает загрузку изображения, генерацию и удаление файла у провайдера. Это маленькая диагностическая выборка, а не статистический рейтинг моделей.

Контрольные ответы математики: корни 2 и 3; **19/7**; производная `3x²−4`. На фото дана сложная дробь `(3/4 + 5/6)/(7/12)`, поэтому 19/12 — ответ только для числителя, а не всего выражения. Контрольные ответы физики: **6 Н, 4 Дж, 2 А**.

| Модель | Фото математики | Фото физики | Наблюдение |
|---|---|---|---|
| GigaChat-3-Lightning | API 422, 1,14 с | API 422, 1,29 с | Оба запроса с фото отклонены. Отдельный текстовый запрос выполнен; причину ограничения фото не обобщаем на все тарифы. |
| GigaChat-3-Pro | JSON принят, 4,21 с | JSON принят, 3,90 с | Условия распознаны верно. 5 из 6 ответов верны: вместо 19/7 модель дала 3. |
| GigaChat-3-Ultra | JSON принят, 4,19 с | JSON принят, 4,19 с | Условия распознаны верно. 5 из 6 ответов верны: вместо 19/7 модель дала 2. |
| GigaChat-2-Max | Ответ не прошёл проверку формата, 4,31 с | JSON принят, 4,54 с | Все 3 физических ответа верны. Математический лист пользователю не выдан как готовый. |

Первые три модели проверялись до вычислительной проверки; 2-Max — после её добавления. Приведённые ошибки Pro/Ultra относятся именно к исходному ответу модели.

## Решения в приложении

- Рабочий выбор оставлен **GigaChat-3-Ultra**. Pro также прошёл распознавание обоих фото, но на этой выборке нет оснований утверждать, что он надёжнее Ultra.
- Простые задания вида «Вычислите $числовое выражение$» теперь проверяются точной рациональной арифметикой. Поддерживаются дроби, `+ − × ÷`, скобки, ограниченные целые степени и квадратные корни с точным рациональным результатом. Python `eval` не используется.
- Вычисленный ответ помечается в карточке; после ручной правки отметка снимается. Проверка не распространяется на произвольные уравнения, производные, задачи с единицами, округлением или неуверенным распознаванием.
- Две страницы в одном ответе модели однажды дали непригодный результат. Теперь каждая фотография обрабатывается отдельно; объединение и нумерацию выполняет код. Повторная проверка двух копий контрольной страницы вернула **6 заданий** без потерь, обе сложные дроби получили ответ **19/7**.
- Варианты раньше могли повторять исходный лист. Разделены инструкции распознавания и изменения; повтор исходного задания вызывает одну дополнительную попытку, затем понятную ошибку вместо ложного успеха.

После исправления проверены «Другой вариант», «Проще», «Сложнее»: 2,81 с, 1,75 с, 6,65 с соответственно. Все 9 полученных ответов сверены. В более сложном листе появились дополнительные действия с дробями и корнями; степень сложности каждого задания всё ещё требует методической оценки учителя. Параметр сложности не является педагогической гарантией.

## Воспроизведение

```powershell
.\.venv\Scripts\python.exe scripts/compare_models.py --run
.\.venv\Scripts\python.exe scripts/compare_models.py --run --models GigaChat-2-Max --output output/qa/gigachat-2-max.json
# При запущенном run_local.py:
.\.venv\Scripts\python.exe scripts/smoke_live.py --run
```

Команды расходуют квоту API. JSON с результатами сохраняется в `output/qa`, без ключей. Успешный `check_connections.py --gigachat` сам по себе проверяет только доступность списка моделей.

API и настройка TLS: [авторизация GigaChat](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api), [сертификаты](https://developers.sber.ru/docs/ru/gigachat/certificates), [GigaChat 3 Ultra](https://developers.sber.ru/docs/ru/gigachat/models/gigachat-3-ultra).
