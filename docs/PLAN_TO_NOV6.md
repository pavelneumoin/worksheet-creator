## Критерий «готовый продукт»

- Учитель открывает рабочую ссылку MAX и самостоятельно получает лист и ответы из фото на телефоне.
- Сохранённые материалы доступны при повторном входе; чужие личные материалы и файлы недоступны.
- Библиотека позволяет найти, посмотреть, оценить и взять лист за основу; автор может снять публикацию.
- Ошибки распознавания можно исправить без знания LaTeX; перед печатью есть проверка условий и ответов.
- Контейнер собирается и запускается по README, данные сохраняются, зависимости закреплены, CLI-пример работает.
- Есть реальные проверки в MAX, учительский пилот, доказательства участия команды и запасная демонстрация.
