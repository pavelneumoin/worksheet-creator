# Библиотека учительских материалов

Реализована 22 октября 2026 в локальной рабочей копии. Доступ использует те же серверные сессии, что личные материалы. В локальном режиме можно проверить сценарий без настоящего токена MAX; открытого интернет-размещения пока нет.

## Сценарий учителя

1. Сохранить лист в «Мои материалы» и нажать «Поделиться».
2. Указать имя автора и описание, проверить задания и ответы, подтвердить публикацию.
3. Коллега находит лист в «Библиотеке», открывает условия и ответы, ставит оценку или нажимает «Взять за основу».
4. В его личном профиле появляется независимый черновик с указанием автора. Его можно менять и собирать обычным способом.
5. Автор может снять публикацию. Его личный лист и уже сохранённые коллегами копии остаются.

Поиск охватывает тему, класс, условия, описание и автора, без учёта регистра кириллицы. Есть фильтр математики/физики, сортировка по среднему рейтингу (затем числу оценок), новизне, количеству пользователей, взявших за основу, и собственным публикациям. Выдача — по 12 карточек с кнопкой «Показать ещё». При малом числе оценок рейтинг не считается доказательством методического качества.

## Границы публикации

- В библиотеку попадает отдельная версия структуры листа. Правки личного черновика не заменяют опубликованное содержание.
- Видны выбранное имя автора, тема, класс, условия, ответы и примечания. Фотографии, MAX ID, личные PDF/TEX и имя учителя из печатного заголовка не публикуются.
- Один материал — одна действующая публикация. Чтобы опубликовать новую версию, нужно снять предыдущую; старые оценки удаляются и не переносятся на другое содержание.
- Один профиль ставит одну оценку 1–5, которую можно изменить. Самооценка запрещена сервером. Число «взяли за основу» считает разные профили, кроме автора, а не нажатия.
- Удаление исходного личного материала также снимает его публикацию; это указано в подтверждении удаления. Сохранённые коллегами копии и сведения об авторе остаются.
- Авторство основы хранится отдельно от редактируемого содержания. Оно сохраняется при обычном редактировании и сохранении копии; при публикации производного листа показывается исходная основа.
- Вход обязателен и для чтения библиотеки. Все изменения используют имеющуюся CSRF-защиту. Нельзя передать чужой материал как основание для публикации или копирования личного происхождения.

## API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| GET | `/api/v2/library?q=&subject=&sort=rating&page=1` | Карточки, общее число, следующая страница |
| GET | `/api/v2/library/<id>` | Публикация с заданиями и ответами |
| POST | `/api/v2/materials/<id>/publish` | Снимок собственной сохранённой версии: `revision`, `author`, `description`, `reviewed: true` |
| PUT | `/api/v2/library/<id>/rating` | Создать/изменить собственную оценку: `stars` |
| POST | `/api/v2/library/<id>/copy` | Создать личную копию с авторством основы |
| DELETE | `/api/v2/library/<id>` | Снять свою публикацию |

SQLite создаёт дополнительные таблицы при запуске. Старые материалы не публикуются автоматически. Перед обновлением рабочего сервера нужно сохранить копию базы вместе с файлами; схема не удаляет существующие таблицы.

## Проверки

77 автоматических тестов всего, 11 новых по библиотеке. Проверены два подписанных тестовых MAX-профиля и второе устройство, изоляция личных данных, CSRF, конфликт версии при публикации, неизменность снимка, повторные оценки, отказ в самооценке, снятие чужой публикации, копирование и авторство, удаление оригинала, повторная публикация с новым рейтингом, поиск и постраничная выдача. Реальный токен MAX этим проверкам не нужен.

Браузерная проверка использует два локальных профиля на `127.0.0.1` и `localhost`. Пройдены публикация с просмотром ответов, просмотр во втором профиле, изменение оценки 4 → 5 без второго голоса, сохранение основы, изменение темы копии и сохранение авторства. Просмотрены экраны шириной 320, 375 и 390 px. На 320 px ширина страницы равна клиентской ширине 305 px с учётом полосы прокрутки. Исправлены скрытая подпись навигации и размеры звёзд до 44 × 44 px.

После переключения вкладок инструмент управления браузером перестал выполнять нажатия; проверку снятия публикации через интерфейс и повторный проход всех ширин следует повторить. Подтверждение снятия теперь встроено в страницу. Серверный сценарий снятия/повторной публикации и сохранности чужих копий проверен автоматическими тестами и на локальном учебном материале. Учебная публикация и оценки в этой проверке — тестовые данные, не отзывы реальных учителей; проверочные оценки удалены. Снимок сохранённой копии — `output/qa/listok-library-copy-mobile.jpg` (игнорируется Git).

Проверки в MAX на физических телефонах остаются отдельным этапом после получения токена.
