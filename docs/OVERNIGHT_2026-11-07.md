## Видео

Сценарий: вход → демо → рабочий лист и печать → назначение → бланк ответов
→ проверка и автосохранение → кабинет ученика и исправление → статистика завуча
→ быстрый режим в чате. Для показа используются только учебные данные.
Запись не должна содержать личные переписки, ключи входа, токены и имена детей.
