# Визуальное направление «ЛистОК»

Обновлено 21 октября 2026 по запросу владельца проекта: современный минималистичный интерфейс в светло-серой гамме Сферума.

Источник: официальный сайт https://www.sferum.ru/, просмотренные inline CSS 21.10.2026. Открытый брендбук не найден. Ниже — наблюдаемые цвета сайта, а не заявление об официальной полной бренд-палитре.

| Цвет | Использование на сайте / в адаптации |
|---|---|
| `#8742EE` | Основной фиолетовый акцент |
| `#312740` | Основной тёмный текст |
| `#766C8B` | Вторичный текст |
| `#FFFFFF` | Белые поверхности |
| `#FBFAFC` | Очень светлая поверхность |
| `#EFE8FB` | Светло-фиолетовый фон |
| `#9F68F1` | Дополнительный фиолетовый |

Собственные нейтральные дополнения «ЛистОК»: фон `#F4F4F7`, границы `#E7E5EB`, hover `#7131D5`. Они не выдаются за цвета брендбука. Системный шрифт Segoe UI / Arial, минимум теней, радиусы 9–18 px, понятные текстовые кнопки. Название и знак остаются собственными: «ЛистОК», команда «ЛатехТим».

Печатные листы остаются преимущественно чёрно-белыми для обычного школьного принтера.

Формулы: KaTeX 0.19.0, локально поставляется в `app/frontend/vendor/katex`, лицензия MIT сохранена рядом. Внешний CDN для формул не требуется.
